# pyrchen — frontend portfolio

Статическое портфолио: Three.js, частицы, анимация, адаптивная верстка. Без прикладного backend, базы данных и секретов.

## Локальный запуск

```sh
npm ci
npm run build
npm start
```

Предпросмотр: http://127.0.0.1:4173. `preview.mjs` — только локальная раздача файлов через esbuild, не backend приложения. На хостинг загружается **только dist/**; Node.js нужен для сборки, но не для работы опубликованного сайта.

## Проверки

```sh
npm run check
npm test
```

## Данные

- Черновик задачи хранится только в localStorage браузера. Сохранение не отправляет сообщение автору; для связи есть Telegram и почта. При очистке данных браузера черновик пропадёт.
- `public/github-activity.json` — проверенный обезличенный снимок. В интерфейсе указаны дата сбора и период, это не live API. Для обновления нужен новый проверенный снимок и пересборка сайта. Названия и содержимое закрытых репозиториев не публикуются.
- Резюме, имя, контакты и PDF в `public/assets/` предназначены для публикации в портфолио.

## Публикация

Cloudflare Pages: команда сборки `npm run build`, выходная папка `dist`. Можно загрузить готовую папку вручную. Относительные пути позволяют разместить сайт и в подпапке, например на GitHub Pages. Создание репозитория само по себе не включает хостинг сайта.

Не загружать исходную рабочую папку: в эту frontend-версию намеренно не включены backend-модули, базы SQLite, внутренние материалы, резервные копии и авторизация GitHub CLI.
